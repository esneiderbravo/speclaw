# Design — stop-hook-feedback

## Telling the level early

`docHint` used the cache only for the exact file set. Now, without an exact
measurement, it starts one background job unless one is still in flight
(`pending.at` within the grace period and the cache not written since), then
looks for the last measurement whose file set is a subset of today's
(`level-cache.json` now stores `files`). A measured level only rises, so that
level is a safe floor: the hint and the scaffold use it, and the exact
measurement raises it later through `remeasure`. `remeasure`, `reopenIfGrown`
and `measureDiff` accept a measurement so the hook never measures inline.
"Told" now includes the kinds of artifact owed, so an API report owed later at
the same level is still said.

## API surface from the diff

`api-surface.ts` runs one `git diff -U0 <base> -- <files>` plus
`ls-files --others` and tests trimmed changed lines: decorators and router calls
must open the line (a regex or string that mentions one is not a route), Next.js
handlers count only in `app/**/route.*`, DTO files count only on code lines,
contract files count on any change. Test files are skipped. On FAR-1387 it
found the three endpoints and their DTOs in 130 ms. The result feeds
`touchesPublicApi` (and `signals.apiSurface`), and `pendingArtifacts` reads it
from the current files when it has them.

## Reports per discipline

Only at level 2+ (the spec lane the law governs); level 0/1 keep one report.
`scopedTestGate` exposes `affectedTests`' per-package commands; each runs as its
own gate tagged with a discipline from its directory. Repo-wide gates go in
every report. A generated report is never `api.md` — that one is the agent's —
and reports carrying ship's "Generated by" mark that this ship did not write are
removed.

## Stop summary

`stopSummary` builds one line; `ship-on-stop` prints it as
`{"systemMessage": …}` on stdout, which Claude Code shows the user on exit 0.
The hook command stops discarding stdout (ship prints nothing else there).
