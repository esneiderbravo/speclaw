# add-context-budget — measure, publish, and gate speclaw's context cost

## Why

Every MCP tool definition (name + description + JSON Schema) rides in **every**
model request. speclaw currently registers **21 tools**. Descriptions alone are
~650 words; Zod `.describe()` text multiplies the schema cost. Skills, commands,
and always-on agent docs add more. Spec Kit was publicly called out for ~18.6k
command tokens (~93% of Cursor's default chat window)
([github/spec-kit#1401](https://github.com/github/spec-kit/issues/1401)). Competitors
(GSD, Context7) market measured token cuts. speclaw has **no published number**
and no CI gate that fails when the cost rises.

This is roadmap piece 5/19
([`docs/roadmap/platform/token-budget.md`](../../../docs/roadmap/platform/token-budget.md)).
Authority where the feature doc conflicts with verified platform facts:
[`docs/roadmap/02-correcciones-verificadas.md`](../../../docs/roadmap/02-correcciones-verificadas.md)
§2.3 — **`defer_loading` is not author-settable**. Client Tool Search may kick
in above ~10% of context; the server cannot mark tools deferred. The only
controllable levers are fewer registered tools, shorter descriptions/schemas,
smaller skill/instruction surfaces, and less output. That correction is law for
this change: no eager/deferred fiction in the design or the marketing number.

## What

- **Deterministic offline estimator** (`estimateTokens`) and **`measureBudget()`**
  across four surfaces: (A) MCP tool definitions as registered, (B) skills +
  commands, (C) always-on instructions, (D) path-scoped rules (reported, not
  counted in the always-on total).
- **Committed `token-budget.json`** and a suite gate that fails when measured
  totals exceed the declared ceilings, with the full surface table in the
  failure message.
- **`speclaw budget`** (`--json`, optional `--exact` for offline-gated
  calibration only) and a **doctor** section that reports the project's mode and
  cost.
- **`defineTool()`** in `shared/mcp.ts` that enforces per-tool description word
  caps and definition-token caps at registration — **without** any
  `defer_loading` field.
- **Description + schema rewrite** of all 21 tools (names and signatures
  unchanged).
- **`--minimal` exposure profile**: the server **omits** setup/lifecycle tools
  from registration (real lever). Persisted on `.speclaw.json` / `Manifest` and
  honored by `init`, `update`, and `SPECLAW_MINIMAL=1`.
- **JIT lawbook skills**: each workflow skill becomes a short dispatcher +
  `steps/*.md` that name only the next step.
- **Compact project map** (≤300 estimator tokens) regenerated by `compass_index`
  between markers in committed `docs/compass.md`.
- **README** publishes budget vs actual next to Spec Kit's 18.6k.

## Non-goals

- **`defer_loading` / eager–deferred tiers** — not implementable for MCP server
  authors; do not claim deferred tools cost "name only".
- **Consolidating or renaming tools** — that is `tool-surface` (F3). This change
  measures and shrinks definitions; it does not merge `compass_*`.
- **Path-scoping `LAWS.md` into `.claude/rules` with `paths:`** — couples to the
  post-compact / hooks story; out of scope here (document the dependency only).
- **A real BPE tokenizer as a runtime dependency** — contradicts local-first and
  the "light package" pitch. Calibration via Anthropic's token-count API is
  optional, offline-only, never a CI gate.
- **Output-token budgets on tool responses** — useful later; not this change.
- **doctor-provenance `--json` reshape** — doctor gains a context-cost section;
  full provenance JSON is a later piece.

## Migrations

Additive. `Manifest` gains an optional `minimal: boolean` (default `false`).
Existing projects keep full exposure until they opt in. No Compass
`SCHEMA_VERSION` bump. `docs/compass.md` gains managed map markers on next
index when markers are present (scaffold template ships them).
