# Design — stop-hook-cost

- **Test-script scope** (`testScriptPackages`, `affected.ts`): parse the root `scripts.test` for `--workspace`/`-w`/`--workspace=`, `--prefix` and `cd <dir> &&`; map workspace names to directories through the root `workspaces` (array or `{packages}`, one `*` segment). Any unknown reference, `--workspaces`/`-ws`, or no reference returns null — the selection is never narrowed on a guess. `scopedTestGate` filters the selection by those directories and re-plans the commands with `planTestCommand`; when nothing is left the gate runs nothing and its scope says why.
- **Test flags** (`syncTestFlags`, `indexer.ts`): the globs the flags were computed with live in `meta.test_globs`. `buildIndex` (after the walk) and `indexFiles` (under the lock) compare them with the effective config and recompute `files.is_test` for every row only on a mismatch, so the common path costs one meta read.
- **Cooldown** (`ship.ts`): the ship marker gains `at` (written only after passing gates). `shipOnStop` skips as `cooling-down` when the marker is on the same branch and younger than `ship.cooldownMinutes`. The deferred work is not lost: the next stop past the window ships it, and CI gates the PR.
